WEBSITE SƠ ĐỒ TƯƠNG TÁC CLB CƠ ĐIỆN TỬ

1. Mở file index.html bằng trình duyệt để chạy.
2. Các nhân vật có thể click:
   - Chủ nhiệm
   - Phó Chủ nhiệm
   - 03 giảng viên Ban chuyên môn
   - 05 vị trí Ban điều hành
3. Phần Thành viên phía dưới không có hotspot/hồ sơ theo yêu cầu.
4. Muốn sửa thông tin nhân sự: mở app.js và chỉnh mảng const people.
5. Muốn chỉnh vùng click: sửa x, y, w, h (đơn vị % theo ảnh).
6. Ảnh nền nằm tại assets/clb-map.png.

Có thể triển khai trực tiếp lên GitHub Pages / Netlify / hosting tĩnh.
